# Repository Instructions

Before making any changes in this repository:

1. Read `.ai/project.xml` to determine which technology, framework,
   and architecture rules are enabled.
2. Read `.ai/instructions.xml`.
3. Follow the rules specified by `.ai/instructions.xml`.
4. Apply all enabled rules when writing, modifying, refactoring,
   or reviewing code.
5. Project-specific overrides take precedence over general rules.
6. Do not claim that tests, builds, or checks passed unless you
   actually ran them.
